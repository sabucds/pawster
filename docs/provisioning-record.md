## Ceilings now live

- Resend transactional: 100/day, 3,000/month. ADR 0009 budgets the digest
  at `100 - 30`, so the $0 ceiling is ~500 weekly subscribers.
  Not reachable in this phase: without a verified domain the only
  deliverable address is this account's own, so the binding limit is
  domain verification, not the quota.
- R2: 10 GB-month, 1M Class A, 10M Class B, egress free. The only
  component that bills instead of failing. ADR 0012 puts the lifetime
  ceiling at ~9,500 animals, revised down from ~12,500.
- Images: 5,000 transformations per calendar month, recurring. The
  derivative set costs `2N + 2` per animal, so ~350-500 new animals
  per month. Fails closed at error 9422, with no `onerror` fallback
  for the binding (ADR 0012).
- Queues: 10,000 operations/day; messages retained 24h on Free.
- D1: 500 MB per database.

## Deferred by `--no-domain`

Four stages need a domain and its Cloudflare zone, and did not run:

- **2** the domain, and its zone on Cloudflare
- **10** Images transformations (observation only; needs a zone)
- **13** the Resend sending subdomain
- **14** the Resend DNS records (MX, SPF, DKIM)

Consequence: Resend reaches only this account's own address, so shelter
sign-in codes (ADR 0013), admin verification links (ADR 0002) and the
subscriber digest (ADR 0009) work for the operator alone. Onboarding a
second shelter, or one real subscriber, requires a domain.

See [ADR 0014](adr/0014-domain-free-prototype-phase.md).

## Still unsettled

ADR 0012 says the originals lifecycle rule "also collects abandoned upload
sessions, so neither needs code" in ADR 0010's daily purge. It plainly collects
an abandoned session's **originals**, and R2's default multipart-abort rule
collects incomplete uploads. But ADR 0012 also stages *derivatives* before the
animal row is committed, and those are written to `pawster-media`, which
neither rule touches — so an abandoned session appears to strand its
derivatives there permanently. That is either a second lifecycle rule on a
staging prefix or a line of purge code, and it is a decision rather than a
mechanical gap. Worth settling before the upload path is built.
